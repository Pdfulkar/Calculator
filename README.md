# Calculator Web Application

A simple yet functional web-based calculator built with HTML, CSS, and JavaScript. Perform basic arithmetic operations, clear inputs, and enjoy a responsive design for seamless use across devices.

![Calculator Preview](https://github.com/user-attachments/assets/220edcd4-d3db-4d3b-9089-48744ff5c04e)


## Features

- **Basic Operations**: Addition (+), Subtraction (-), Multiplication (×), Division (÷)
- **Decimal Support**: Perform calculations with decimal numbers
- **Clear & Delete**: 
  - `C` button to reset the calculator
  - `DEL` button to remove the last character
- **Keyboard Support**: Use your keyboard for inputs (0-9, +, -, *, /, Enter, Backspace)
- **Error Handling**: Displays "Error" for invalid operations (e.g., division by zero)
- **Responsive Design**: Works on desktop, tablet, and mobile screens
